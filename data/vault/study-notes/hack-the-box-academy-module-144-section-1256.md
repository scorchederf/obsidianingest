# Hack The Box - Academy Module 144 Section 1256

## Overview
This module covers the use of tools such as `gobuster`, `hydra`, and `john` for web attacks. The content is part of the Hack The Box Academy and is designed to teach techniques for identifying and exploiting vulnerabilities in web applications.

## Gobuster
Gobuster is a tool used for directory and subdomain enumeration. It can be used to find hidden directories and files on a web server. The module provides examples of how to use Gobuster to scan a target domain for potential vulnerabilities.

## Hydra
Hydra is a network login cracker that supports many different services. The module explains how to use Hydra to perform brute force attacks on web applications, such as HTTP, HTTPS, FTP, and more. Examples are provided to demonstrate the use of Hydra in a real-world scenario.

## John the Ripper
John the Ripper is a password cracking tool that can be used to crack weak passwords. The module covers the basics of using John the Ripper to crack passwords, including how to use wordlists and dictionary attacks. Examples are provided to illustrate the process.
