# Shells & Payloads

## Introduction
This module covers the use of shells and payloads in cybersecurity. It provides an overview of various techniques and tools used to gain access to systems and execute commands.

## Shells
Shells are command-line interfaces that allow users to interact with the operating system. They can be used to execute commands, manage files, and perform other administrative tasks. Common shells include Bash, PowerShell, and CMD.

## Payloads
Payloads are pieces of code or scripts designed to perform specific actions, such as stealing credentials, exfiltrating data, or maintaining persistence. They can be delivered through various methods, including web shells, reverse shells, and file uploads.
