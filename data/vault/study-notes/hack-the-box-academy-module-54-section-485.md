# Hack The Box - Academy Module 54 Section 485

## Overview
This section covers various techniques and tools used in penetration testing, including enumeration, password cracking, and SQL injection. The techniques and tools discussed are part of the Hack the Box Academy module 54, section 485.

## Enumeration Techniques
- **Nmap**: Used for network scanning and service enumeration.
- ** Nikto**: A web server scanner that performs comprehensive tests against web servers for multiple security issues.
- **SQLMap**: An automated open-source tool that helps to detect and exploit SQL injection vulnerabilities.
- **John the Ripper**: A password cracker that supports a wide range of cryptographically weak password hashing algorithms.

## Password Cracking
- **John the Ripper**: Used to crack weak passwords by brute-forcing or using dictionary attacks.
- **Hashcat**: Not mentioned in this section, but often used alongside John the Ripper for more advanced password cracking.

## SQL Injection
- **SQLMap**: Used to detect and exploit SQL injection vulnerabilities in web applications.
