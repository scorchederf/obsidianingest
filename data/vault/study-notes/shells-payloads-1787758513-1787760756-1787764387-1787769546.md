# Shells & Payloads

## Introduction
In this section, we will explore the various shells and payloads that can be used in cybersecurity operations. This includes tools like Mimikatz, PowerShell, and commands such as net, netsh, netstat, ping, whoami, etc.

## Mimikatz
Mimikatz is a powerful tool used for privilege escalation and credential dumping. It can be used to extract credentials from memory, Kerberos tickets, and more. Here are some key commands:

- `sekurlsa::logonpasswords`: Extracts logon passwords from memory.
- `privs`: Displays current privileges.
- `token::elevate`: Elevates the current token to SYSTEM.

## PowerShell
PowerShell is a versatile scripting language that can be used for a wide range of tasks, including creating and managing shells. Here are some common commands:

- `Invoke-WebRequest`: Used to send HTTP requests.
- `Invoke-Command`: Executes commands on remote systems.
- `New-PSDrive`: Creates a new drive mapping.

## Net, Netsh, Netstat, Ping, Whoami
These are built-in Windows commands that can be used for reconnaissance and network analysis:

- `net`: Used to manage network connections and services.
- `netsh`: Configures network interfaces and protocols.
- `netstat`: Displays active TCP and UDP connections.
- `ping`: Tests network connectivity.
- `whoami`: Displays the current user's identity.

## HTTP & HTTPS
HTTP and HTTPS are commonly used protocols for web traffic. They can be exploited for various purposes, such as web shells and reverse shells. Here are some key points:

- HTTP: Used for unencrypted web traffic.
- HTTPS: Used for encrypted web traffic.
