# Hack The Box - Academy Module 35 Section 224

## Introduction
This module covers the use of tools such as Ettercap, Evil-WinRM, Burpsuite, and BetterCap to perform various network and penetration testing tasks.

## Ettercap
Ettercap is a suite of tools for man-in-the-middle attacks. It can be used to intercept and modify network traffic. The module covers how to use Ettercap to perform ARP poisoning and sniffing.

## Evil-WinRM
Evil-WinRM is a tool for executing commands on Windows systems over a network. The module explains how to use Evil-WinRM to gain remote access and execute commands on a target machine.

## Burpsuite
Burpsuite is a web application security testing platform. The module covers how to use Burpsuite to perform various security testing tasks, such as intercepting and modifying HTTP traffic.

## BetterCap
BetterCap is a network security tool that can be used for various purposes, including network scanning and packet manipulation. The module explains how to use BetterCap to perform network reconnaissance and packet analysis.
