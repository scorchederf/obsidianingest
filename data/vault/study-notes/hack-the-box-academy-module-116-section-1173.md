# Hack The Box - Academy Module 116 Section 1173

## Introduction
This section covers the basics of the Hack The Box Academy module 116, section 1173. The module focuses on the use of Metasploit and other tools to perform a penetration test on a target machine.

## Metasploit Basics
The section introduces the use of Metasploit, a powerful penetration testing framework. It covers the installation and basic configuration of Metasploit, as well as how to use it to exploit vulnerabilities in the target machine.

## Exploiting Vulnerabilities
The module provides detailed steps on how to identify and exploit vulnerabilities using Metasploit. It includes commands and examples of how to use Metasploit modules to gain access to the target machine.

## Post-Exploitation
After gaining access, the section covers various post-exploitation techniques, such as privilege escalation, lateral movement, and data exfiltration. It provides examples of how to use Metasploit and other tools to maintain access and gather information from the target machine.
