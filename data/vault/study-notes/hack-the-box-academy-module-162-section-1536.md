# Hack The Box - Academy Module 162 Section 1536

## Overview
This module covers various techniques and tools used in ethical hacking, including network scanning, service enumeration, and privilege escalation. The techniques and tools discussed are part of the MITRE ATT&CK framework.

## Network Scanning
The module starts with a detailed explanation of using `nmap` for network scanning. Key commands and options are provided to discover open ports and services on the target network.

## Service Enumeration
Service enumeration is covered using tools like `netcat`, `curl`, and `wget`. The module explains how to identify and interact with services running on the target system, including HTTP and HTTPS services.

## Privilege Escalation
The module delves into various privilege escalation techniques, including those covered in MITRE ATT&CK techniques T1003, T1008, T1020, T1068, T1132, and T1190. Specific examples and commands are provided to demonstrate how to escalate privileges.

## Tools and Techniques
Several tools and techniques are discussed, including the use of Python scripts for automating tasks. The module also covers the use of `nmap` for identifying open ports and services, and `netcat` for establishing reverse shells.
