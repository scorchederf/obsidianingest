# Hack The Box - Academy Module 110 Section 1053

## Overview
This section covers the techniques and tools used in the Hack The Box - Academy module 110, section 1053. The focus is on password cracking and credential harvesting.

## Password Cracking
The module introduces the use of tools like `john` and `mimikatz` for password cracking. It covers the process of extracting hashes from memory and using them to crack passwords.

## Credential Harvesting
The section also covers the use of tools such as `lazagne` for harvesting credentials from the system. This includes commands and techniques for running `lazagne` and understanding its output.
