# File Transfers

## Introduction
File transfers are a common method of moving data between systems. This can be done using various protocols and tools, and is often a key step in gaining access to a system or exfiltrating data.

## Common File Transfer Protocols
The following protocols are commonly used for file transfers:
- FTP
- SFTP
- HTTP
- HTTPS
- SMB
- SCP
- SFTP
- TFTP

## Tools and Techniques
Several tools can be used for file transfers, including:
- WinSCP
- FileZilla
- Cyberduck
- SCP
- SFTP
- TFTP
- HTTP/HTTPS
- SMB
- FTP

These tools can be used to transfer files between systems, and can often be used to gain access to a system or exfiltrate data.

## Best Practices
When performing file transfers, it is important to follow best practices to ensure the security of the data being transferred. This includes:
- Using secure protocols (SFTP, HTTPS, etc.)
- Authenticating and authorizing users
- Encrypting data in transit and at rest
- Monitoring and logging file transfer activity
