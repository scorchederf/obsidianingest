# Hack The Box - Academy Module 115 Section 1103

## Overview
This module covers the process of identifying and exploiting vulnerabilities in a web application. The main focus is on using tools such as Burp Suite, Ettercap, John the Ripper, and Mimikatz to identify and exploit vulnerabilities, as well as using Nmap and Wpscan for network and service enumeration.

## Tools and Techniques
The following tools and techniques are covered in the module:

- **Burp Suite**: A web application security testing tool used for intercepting and manipulating HTTP(S) traffic.

- **Ettercap**: A suite of network tools for man-in-the-middle attacks, used for sniffing and manipulating network traffic.

- **John the Ripper**: A password cracking tool that can be used to crack weak passwords.

- **Lazagne**: A tool used to extract passwords from various applications and services.

- **Mimikatz**: A post-exploitation tool used to extract credentials from memory.

- **Nmap**: A network scanning tool used for network and service enumeration.

- **Wpscan**: A tool used to identify and exploit vulnerabilities in WordPress installations.
