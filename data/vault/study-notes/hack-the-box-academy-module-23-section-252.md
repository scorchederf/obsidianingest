# Hack The Box - Academy Module 23 Section 252

## Overview
This section covers the process of enumerating a target machine, identifying vulnerabilities, and exploiting them to gain access and escalate privileges. It includes practical examples and commands for using tools like nmap, netcat, curl, wget, dirb, nikto, sqlmap, and john.

## Enumeration
The section begins with a basic nmap scan to gather information about the target machine. It then uses netcat, curl, and wget to further explore the network and web services. Specific commands and examples are provided to demonstrate how to use these tools effectively.

## Web Application Enumeration
The section details the use of tools like dirb and nikto to enumerate web applications and identify potential vulnerabilities. Examples of commands and their outputs are provided to illustrate the process.

## Exploitation
The section covers the exploitation of identified vulnerabilities. It includes examples of using sqlmap for SQL injection attacks and john for password cracking. Commands and steps are provided to demonstrate the exploitation process.

## Post-Exploitation
The section discusses post-exploitation activities such as establishing a reverse shell and privilege escalation. Practical examples and commands are provided to set up a reverse shell using netcat and to escalate privileges using tools like john.
