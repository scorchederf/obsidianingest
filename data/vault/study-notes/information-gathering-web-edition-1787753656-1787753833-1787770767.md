# Information Gathering - Web Edition

## Introduction
This module covers the basics of web information gathering, including the use of various tools and techniques to discover information about a target website. The goal is to gather as much information as possible to aid in further penetration testing activities.

## Tools and Techniques
The following tools and techniques are covered in the module:

- **ffuf**: A fast and efficient tool for brute-forcing directories and files.
- **whatweb**: A tool that performs web fingerprinting to gather information about the target.
- **nikto**: A web server scanner that checks for vulnerabilities and misconfigurations.
- **wpscan**: A tool specifically designed for WordPress sites to check for vulnerabilities.
- **dirb**: A directory brute-forcing tool.
- **gobuster**: Another directory brute-forcing tool.
- **nmap**: A powerful network scanning tool that can be used for web information gathering.
- **curl** and **wget**: Tools for making HTTP requests and downloading files.
- **httpx**: A tool for discovering open ports and services.
- **masscan**: A fast network scanner that can be used to discover open ports.
- **dnsenum**: A tool for enumerating DNS records.
- **dnsrecon**: A tool for DNS enumeration and analysis.
- **dnsx**: A tool for DNS enumeration and analysis.
- **subfinder**: A tool for discovering subdomains.
- **assetfinder**: A tool for discovering subdomains and assets.
- **waybackurls**: A tool for retrieving URLs from the Wayback Machine.
- **aquatone**: A tool for creating a visual report of a target website.

These tools are used to gather information such as open ports, services, directories, files, and subdomains.

## Techniques
The module covers the following techniques:

- **T1039**: Collection of sensitive data from network traffic.
- **T1089**: Collection of sensitive data from unsecured web resources.
- **T1585**: Discovery of network devices and services.
