# Using the Metasploit Framework

## Introduction
This section introduces the Metasploit Framework, a powerful tool for penetration testing and ethical hacking. It covers the basics of using Metasploit for various tasks, including exploitation, post-exploitation, and reporting.

## Installation
To install Metasploit, follow these steps:

1. Install Ruby and necessary dependencies.
2. Download and install Metasploit from the official website.
3. Initialize the Metasploit database using the command: `msfdb init`.

## Basic Commands
Here are some basic commands to get started with Metasploit:

- `msfconsole`: Launch the Metasploit console.
- `search <keyword>`: Search for modules by keyword.
- `use <module>`: Select a module for use.
- `show options`: Display the options for the current module.
- `set <option> <value>`: Set module options.
- `run`: Execute the current module.

## Exploitation
Metasploit can be used for various types of exploitation, such as remote code execution, privilege escalation, and more. Here’s an example of using Metasploit to exploit a service:

1. Search for a suitable exploit module: `search exploit <target-service>`
2. Use the module: `use exploit/multi/http/<target-service>`
3. Set the necessary options: `set RHOST <target-ip>`
4. Run the exploit: `run`
5. If successful, the payload will be executed on the target.

## Post-Exploitation
After gaining access, you can use Metasploit for post-exploitation tasks, such as maintaining access, gathering information, and cleaning up traces. Here’s an example of using Metasploit for post-exploitation:

1. Use a post-exploitation module: `use post/multi/gather/credentials`
2. Set the necessary options: `set RHOST <target-ip>`
3. Run the module: `run`
4. Gathered credentials will be displayed in the console.

## Reporting
Metasploit provides tools for generating reports to document your findings. Here’s how to generate a report:

1. Start the reporting module: `use post/reporting/html`
2. Set the necessary options: `set TARGET <target-ip>`
3. Run the module: `run`
4. The report will be saved in the specified directory.
