# Web Attacks

## Overview
This study note covers web attacks, which are techniques used to exploit vulnerabilities in web applications. The focus is on using Burp Suite for web application security testing.

## Tools
- **Burp Suite**: A powerful tool for web application security testing that includes features for intercepting and modifying HTTP traffic, performing automated and manual attacks, and analyzing vulnerabilities.
