# Hack The Box - Academy Module 144 Section 1255

## Overview
This module covers various techniques and tools used in web application penetration testing. It includes topics such as web application scanning, SQL injection, and brute-forcing.

## Web Application Scanning
The module discusses the use of tools like Burp Suite, Ettercap, and Fierce for scanning web applications. It covers techniques such as crawling and enumeration to identify potential vulnerabilities.

## SQL Injection
SQL injection techniques are covered, including the use of tools like SQLMap and Nuclei. The module explains how to identify and exploit SQL injection vulnerabilities in web applications.

## Brute-forcing
Brute-forcing techniques and tools such as John the Ripper and L0phtCrack are discussed. The module covers how to use these tools to crack passwords and gain access to systems.

## Password Cracking
Password cracking techniques are covered, including the use of tools like Hashcat and HashID. The module explains how to crack hashes and gain access to systems with weak passwords.

## Web Application Exploitation
The module covers various web application exploitation techniques, including the use of tools like OWASP ZAP and Nmap. It discusses how to identify and exploit vulnerabilities in web applications.

## Vulnerability Scanning
The module covers the use of tools like Nmap, Nikto, and Wpscan for vulnerability scanning. It explains how to use these tools to identify and exploit vulnerabilities in web applications.
