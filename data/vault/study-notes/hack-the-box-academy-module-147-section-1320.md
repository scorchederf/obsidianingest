# Hack The Box - Academy Module 147 Section 1320

## Introduction
This section of the Hack The Box Academy Module 147 focuses on the use of various tools and techniques to perform password cracking and enumeration tasks. The content covers a range of tools and methods that can be used to gain access to systems and extract sensitive information.
