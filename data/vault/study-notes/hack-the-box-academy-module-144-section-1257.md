# Hack The Box - Academy Module 144 Section 1257

## Introduction
This module covers the use of various tools to perform directory and file enumeration on a target system. The techniques discussed include the use of tools like gobuster, ffuf, dirb, and fierce to discover hidden directories and files.

## Tools and Techniques
The following tools and techniques are covered in this module:

- **Gobuster**: A tool used for directory and file enumeration. It can be used to scan directories for hidden files and directories.

- **FFUF**: Another tool for directory and file enumeration. It is known for its speed and efficiency in scanning large directories.

- **Dirb**: A tool that performs brute-force directory and file enumeration. It is useful for finding hidden files and directories.

- **Fierce**: A tool that performs aggressive directory and file enumeration. It is known for its ability to find hidden files and directories that are not easily accessible.

- **Nmap**: A tool that can be used for scanning directories and files, although it is not specifically designed for this purpose.
