# Hack The Box - Academy Module 58 Section 697

## Overview
This module covers various techniques and tools used in web application penetration testing, focusing on password cracking, web attacks, and reconnaissance. The techniques and tools discussed include brute-forcing, password cracking, and web attacks. The module also covers the use of tools such as bettercap, burpsuite, crackmapexec, credking, crowbar, crunch, cupp, curl, dig, nmap, nikto, and sqlmap.

## Tools
- **bettercap**: A network security tool that can be used for various network attacks, including password sniffing and man-in-the-middle attacks.
- **burpsuite**: A web application security testing tool that can be used for intercepting and manipulating HTTP(S) traffic.
- **crackmapexec**: A tool for performing network reconnaissance and password auditing.
- **credking**: A tool for credential harvesting and password cracking.
- **crowbar**: A tool for automating the process of password cracking.
- **crunch**: A password generator that can be used to generate a wide range of password combinations.
- **cupp**: A tool for generating wordlists for use in password cracking.
- **curl**: A command-line tool for transferring data with URLs.
- **dig**: A command-line tool for querying DNS servers.
- **nmap**: A network scanning tool that can be used for port scanning and service detection.
- **nikto**: A web server scanner that can be used for identifying vulnerabilities in web applications.
- **sqlmap**: A tool for automating the process of detecting and exploiting SQL injection vulnerabilities.

## Techniques
- **Brute-forcing**: Techniques for guessing or cracking passwords using automated tools and scripts.
- **Password Cracking**: Techniques for recovering passwords using tools like crackmapexec, credking, and crowbar.
- **Web Attacks**: Techniques for attacking web applications, including SQL injection and cross-site scripting (XSS).

## Tactics
- **T1003**: Collection of sensitive data.
- **T1008**: Discovery of shared resources.
- **T1020**: Execution of commands or scripts.
- **T1077**: Discovery of remote hosts.
- **T1110**: Discovery of remote services.
- **T1132**: Discovery of local shared resources.
- **T1555**: Discovery of remote systems.
