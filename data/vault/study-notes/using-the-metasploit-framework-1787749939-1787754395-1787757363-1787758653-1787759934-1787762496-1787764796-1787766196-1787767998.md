# Using the Metasploit Framework

## Introduction
The Metasploit Framework is a powerful tool for penetration testers and security researchers. It provides a wide range of modules for exploiting vulnerabilities, conducting reconnaissance, and post-exploitation activities. This study note covers the basics of using the Metasploit Framework.

## Installation
To install Metasploit, follow these steps:

1. Install Ruby: 
   ```bash
   sudo apt-get update
   sudo apt-get install ruby
   ```
2. Install Metasploit: 
   ```bash
   git clone https://github.com/rapid7/metasploit-framework.git
   cd metasploit-framework
   gem install bundler
   bundle install
   ```
3. Start the Metasploit console: 
   ```bash
   ./msfconsole
   ```

## Basic Commands
Here are some basic commands to get started with Metasploit:

- `help`: Display a list of commands.
- `search <keyword>`: Search for modules by keyword.
- `show <type>`: Display a list of modules by type (e.g., exploits, payloads, auxiliary).
- `use <module>`: Select a module to use.
- `set <option> <value>`: Set options for the selected module.
- `run`: Execute the module.

## Example: Exploiting a Vulnerability
Let's say we want to exploit a vulnerability using the Metasploit Framework. Here's an example:

1. Search for a suitable exploit: 
   ```bash
   search exploit
   ```
2. Use the exploit module: 
   ```bash
   use exploit/unix/ssh/ssh_login
   ```
3. Set the options: 
   ```bash
   set RHOSTS 192.168.1.100
   set USERNAME admin
   set PASSWORD password
   ```
4. Run the exploit: 
   ```bash
   run
   ```

## Post-Exploitation
After successfully exploiting a target, you can use Metasploit for post-exploitation activities. Here are some useful modules:

- `sessions`: Manage sessions with the target.
- `shell`: Open a shell on the target.
- `meterpreter`: Execute Meterpreter sessions.
- `upload`: Upload files to the target.
- `download`: Download files from the target.
