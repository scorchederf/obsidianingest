# Information Gathering - Web Edition

## Introduction
This module covers the techniques and tools used for information gathering in web environments. It includes passive and active subdomain enumeration, crawling, file inclusion, and SQL injection.

## Passive Subdomain Enumeration
Passive subdomain enumeration involves gathering subdomains without directly interacting with the target. Tools such as `aquatone`, `burpsuite`, `cewl`, `crowbar`, `droopescan`, `fierce`, `gobuster`, `hydra`, `john`, `joomlascan`, `lazagne`, `nmap`, `nikto`, `nuclei`, `owasp-zap`, `sqlmap`, and `wpscan` are used for this purpose.

## Active Subdomain Enumeration
Active subdomain enumeration involves directly interacting with the target to gather subdomains. This can be done using tools like `aquatone`, `burpsuite`, `cewl`, `crowbar`, `droopescan`, `fierce`, `gobuster`, `hydra`, `john`, `joomlascan`, `lazagne`, `nmap`, `nikto`, `nuclei`, `owasp-zap`, `sqlmap`, and `wpscan`.

## Crawling
Crawling involves traversing the website to discover hidden or non-standard pages. Tools such as `aquatone`, `burpsuite`, `cewl`, `crowbar`, `droopescan`, `fierce`, `gobuster`, `hydra`, `john`, `joomlascan`, `lazagne`, `nmap`, `nikto`, `nuclei`, `owasp-zap`, `sqlmap`, and `wpscan` are used for this purpose.

## File Inclusion
File inclusion involves exploiting file inclusion vulnerabilities to gain access to sensitive files. Techniques such as directory traversal and remote file inclusion are covered.

## SQL Injection
SQL injection involves exploiting SQL injection vulnerabilities to gain access to the database. Tools such as `sqlmap` and `owasp-zap` are used for this purpose.
