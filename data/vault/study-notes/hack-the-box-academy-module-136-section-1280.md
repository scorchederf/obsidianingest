# Hack The Box - Academy Module 136 Section 1280

## Overview
This module covers the use of Burp Suite, Ettercap, Gobuster, and Hydra for web application security testing and enumeration.

## Burp Suite
Burp Suite is a powerful web application security testing tool. It includes features such as proxying, scanning, and analysis of web applications. The module covers how to use Burp Suite to intercept and analyze HTTP(S) traffic.

## Ettercap
Ettercap is a suite of network tools for man-in-the-middle attacks. The module covers how to use Ettercap to intercept and manipulate network traffic, including ARP spoofing and packet injection.

## Gobuster
Gobuster is a directory and subdomain brute-forcing tool. The module covers how to use Gobuster to enumerate directories and subdomains of a target web application.

## Hydra
Hydra is a network login cracker. The module covers how to use Hydra to perform brute-force attacks on various protocols, including HTTP, FTP, and SSH.
