# SQLMap Essentials

## Introduction
SQLMap is an open-source penetration testing tool that automates the process of detecting and exploiting SQL injection flaws and taking over of database servers. With more than 3000 tested settings, SQLMap features a powerful engine to discover and make the most of SQL injection vulnerabilities.

## Installation
SQLMap can be installed via pip or by downloading the source code and running the setup script. To install using pip, run the following command:

```
$ pip install sqlmap
```

For manual installation, download the latest version from the official GitHub repository and follow the instructions provided in the README file.

## Basic Usage
To use SQLMap, you need to provide the target URL and the parameter that is suspected to be vulnerable to SQL injection. Here is a basic command to test a URL for SQL injection:

```
$ sqlmap -u 'http://example.com/vulnerable-param' --data='id=1' --level=5 --risk=3
```

This command performs a level 5 test with a risk level of 3, which is a balance between speed and accuracy.

## Advanced Options
SQLMap offers a wide range of options to customize the scan. Some of the key options include:

- `--level`: Set the level of the test (1-5, default is 1).
- `--risk`: Set the risk level (1-3, default is 1).
- `--technique`: Specify the technique to use (e.g., `E`, `B`, `U`, `T` for UNION, Error, Boolean, and Time-based).
- `--batch`: Run in batch mode (no user interaction).
- `--threads`: Set the number of threads to use (default is 1).
- `--tamper`: Apply tamper scripts to payloads (e.g., `basic`, `space2comment`, `space2and`).
- `--dump`: Dump the database contents.

## Common Techniques
SQLMap supports various techniques to detect and exploit SQL injection vulnerabilities. Some of the commonly used techniques include:

- **T1003**: SQL Injection - Statement
- **T1008**: SQL Injection - Blind
- **T1020**: SQL Injection - Time-Based Blind
- **T1068**: SQL Injection - Union-Based
- **T1098**: SQL Injection - Error-Based
- **T1110**: SQL Injection - Blind Time-Based
- **T1132-001**: SQL Injection - Union-Based
- **T1190**: SQL Injection - Time-Based Blind
- **T1555-004**: SQL Injection - Union-Based

## Example Scenarios
Here are some example scenarios where SQLMap can be used:

1. **Detecting SQL Injection**: Use the `--level` and `--risk` options to perform a thorough test.

2. **Exploiting SQL Injection**: Use the `--dump` option to extract database contents.

3. **Using Tamper Scripts**: Apply tamper scripts to payloads to bypass WAFs or other security measures.
