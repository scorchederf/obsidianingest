# Hack The Box - Academy Module 58 Section 530

## Introduction
This section covers the basics of web application security and the importance of understanding common vulnerabilities and attack vectors.

## Web Application Security
The course introduces the concept of web application security, emphasizing the need to understand and mitigate common vulnerabilities such as SQL injection, cross-site scripting (XSS), and cross-site request forgery (CSRF).

## Vulnerability Scanning
The course covers the use of tools like `gobuster`, `dirb`, and `fierce` for directory and path traversal attacks. It also introduces the use of `nmap` for network scanning and `nikto` for web server security scanning. Additionally, `wpscan` is used for WordPress vulnerability scanning.

## Tools and Techniques
The course provides hands-on experience with various tools and techniques, including:

- `gobuster` for directory brute-forcing
- `dirb` for directory enumeration
- `fierce` for subdomain enumeration
- `nmap` for network scanning
- `nikto` for web server security scanning
- `wpscan` for WordPress vulnerability scanning
