# Hack The Box - Academy Module 103 Section 973

## Overview
In this module, we will be focusing on web application attacks and reconnaissance techniques. The main objectives are to identify vulnerabilities in a web application and exploit them to gain access to the system.

## Tools
The following tools will be used throughout the module:

- **bettercap**: A network tool that can be used for various network attacks, including HTTP and HTTPS traffic manipulation.
- **burpsuite**: A powerful web application security testing tool that can be used for intercepting and modifying HTTP(S) traffic.
- **dirb**: A web directory and file brute-forcing tool that can be used to discover hidden directories and files on a web server.
- **nmap**: A network scanning tool that can be used to discover open ports and services on a target system.
- **sqlmap**: A tool for automating SQL injection attacks and database takeover.

## Reconnaissance
The first step in any web application attack is reconnaissance. This involves gathering information about the target web application, such as its version, running services, and potential vulnerabilities. The following techniques will be used for this purpose:

- **nmap**: To scan the target for open ports and services.
- **dirb**: To brute-force directories and files on the target web application.
- **burpsuite**: To intercept and analyze HTTP(S) traffic to identify potential vulnerabilities.

## Exploitation
Once potential vulnerabilities have been identified, the next step is to exploit them. The following techniques will be used for this purpose:

- **sqlmap**: To exploit SQL injection vulnerabilities and gain access to the database.
- **bettercap**: To manipulate HTTP(S) traffic and perform various network attacks.
