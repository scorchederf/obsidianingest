# Hack The Box - Academy Module 51 Section 1592

## Introduction
This module covers various techniques and tools for web application penetration testing, including brute-forcing, crawling, file inclusion, password cracking, and SQL injection. The focus is on using tools like BetterCap, Burp Suite, cewl, cmd-jsp, crackmapexec, credking, crowbar, crunch, cupp, curl, dnsenum, donpapi, and droopescan.

## Tools
- **BetterCap**: A network security tool that can be used for various network attacks, including brute-forcing and SQL injection.
- **Burp Suite**: A web application security testing tool that can be used for intercepting and manipulating HTTP(S) traffic.
- **cewl**: A tool for generating wordlists from web pages, useful for brute-forcing and password cracking.
- **cmd-jsp**: A tool for generating JSP files, which can be used for file inclusion attacks.
- **crackmapexec**: A tool for performing network enumeration and credential dumping.
- **credking**: A tool for credential dumping and privilege escalation.
- **crowbar**: A tool for automating web application security testing.
- **crunch**: A tool for generating wordlists, useful for brute-forcing and password cracking.
- **cupp**: A tool for generating wordlists from common passwords.
- **curl**: A command-line tool for transferring data with URLs, often used for testing web applications.
- **dnsenum**: A tool for performing DNS enumeration, useful for passive infrastructure identification.
- **donpapi**: A tool for interacting with the Windows Security Accounts Manager (SAM) database, useful for credential dumping.
- **droopescan**: A tool for scanning and exploiting WordPress installations.

## Techniques
- **Brute-forcing**: Techniques for guessing passwords or credentials, often using tools like crackmapexec and credking.
- **Crawling**: Techniques for automating the process of discovering and testing web application endpoints, often using tools like BetterCap and Burp Suite.
- **File Inclusion**: Techniques for including external files in web applications, often used for exploiting vulnerabilities.
- **Password Cracking**: Techniques for recovering passwords, often using tools like crunch and cupp.
- **SQL Injection**: Techniques for exploiting SQL injection vulnerabilities, often using tools like BetterCap and Burp Suite.

## Tactics
- **Passive Infrastructure Identification**: Techniques for passively identifying infrastructure, often using tools like dnsenum.
- **Active Subdomain Enumeration**: Techniques for actively enumerating subdomains, often using tools like BetterCap and Burp Suite.

## Services
- **HTTP**: The Hypertext Transfer Protocol, used for transferring web pages and other web content.
- **HTTPS**: The secure version of HTTP, used for transferring web content over a secure connection.
