# Using Web Proxies

## Introduction
Web proxies can be used to route HTTP requests through a third-party server, providing anonymity and bypassing network restrictions. This technique is useful for ethical hackers to test and exploit web applications from different locations or IP addresses.

## Using Proxychains
Proxychains is a tool that allows you to route all network connections through a proxy server. To use it, you need to configure the `proxychains.conf` file to specify the proxy server details. Here’s an example configuration:

```ini
[ProxyList]
# Example proxy
http  127.0.0.1 8080
```

Once configured, you can use `proxychains` followed by any command to route the traffic through the proxy. For example, to use `wget` through the proxy, you would run:

```bash
proxychains wget http://example.com
```

Similarly, you can use `curl` with `proxychains` to make HTTP requests through the proxy.

## Using Wget
Wget is a command-line tool for downloading files from the web. To use it with a web proxy, you can specify the proxy settings in the `wget` command. For example:

```bash
wget --proxy=on --proxy-user=your_username --proxy-password=your_password http://example.com
```

Alternatively, you can set the environment variables before running `wget`:

```bash
export http_proxy=http://your_username:your_password@proxy_server:port
export https_proxy=http://your_username:your_password@proxy_server:port
wget http://example.com
```

This will route the `wget` requests through the specified proxy.

## Using Curl
Curl is a command-line tool for transferring data with URLs. To use it with a web proxy, you can set the proxy settings in the `curl` command. For example:

```bash
curl --proxy http://your_username:your_password@proxy_server:port http://example.com
```

You can also set the proxy settings in the environment variables before running `curl`:

```bash
export http_proxy=http://your_username:your_password@proxy_server:port
export https_proxy=http://your_username:your_password@proxy_server:port
curl http://example.com
```

This will route the `curl` requests through the specified proxy.
