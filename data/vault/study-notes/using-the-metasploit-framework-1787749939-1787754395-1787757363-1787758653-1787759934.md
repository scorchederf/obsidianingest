# Using the Metasploit Framework

## Introduction
This module covers the basics of using the Metasploit Framework, a powerful tool for penetration testing and ethical hacking. It provides a comprehensive guide to setting up and using Metasploit to perform various types of attacks and tests.

## Setting Up Metasploit
To set up Metasploit, you need to install it on your system. The installation process can vary depending on your operating system. For Linux, you can use the following command to install Metasploit:

```bash
sudo apt-get install metasploit-framework
```

For Windows, you can download the Metasploit Framework from the official website and run the installer.

## Navigating the Metasploit Console
Once installed, you can start the Metasploit console by running the following command:

```bash
msfconsole
```

The Metasploit console provides a command-line interface for launching various modules and executing penetration testing tasks. You can navigate through the console using the following commands:

- `search` - Search for modules based on a keyword.
- `use` - Select a module to use.
- `show options` - Display the options available for the selected module.
- `set` - Set the values for the options.
- `run` - Execute the module.

## Using Metasploit Modules
Metasploit Framework includes a wide range of modules that can be used for various penetration testing tasks. Here are a few examples of how to use some of the modules:

- **Exploits**: These modules are used to exploit vulnerabilities in target systems. For example, to use the `exploit/multi/http/httpd_ntlm` module, you can run the following commands:

  ```bash
  use exploit/multi/http/httpd_ntlm
  set RHOSTS <target_ip>
  set USERNAME <username>
  set PASSWORD <password>
  run
  ```

- **Post-Exploitation**: These modules are used to gain post-exploitation access. For example, to use the `post/multi/gather/enum_groups` module, you can run the following commands:

  ```bash
  use post/multi/gather/enum_groups
  set SESSION <session_id>
  run
  ```

## Conclusion
The Metasploit Framework is a versatile tool that can be used for a wide range of penetration testing tasks. By following the steps outlined in this module, you can effectively use Metasploit to perform various types of attacks and tests. Remember to always use Metasploit for ethical and legal purposes only.
