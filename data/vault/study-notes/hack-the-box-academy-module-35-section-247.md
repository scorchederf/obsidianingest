# Hack The Box - Academy Module 35 Section 247

## Introduction
This module covers the enumeration of services and network infrastructure. The goal is to gather information about the target network and identify potential vulnerabilities.

## Network Scanning
Perform a network scan to identify active hosts and services. Use tools like `nmap` to gather information about the target network.

## Service Enumeration
Enumerate services running on the target hosts. Look for open ports and services that may be vulnerable. Use tools like `nmap` with the `-sV` flag to identify service versions.

## DNS Enumeration
Perform DNS enumeration to gather information about the target domain. Use tools like `dig` and `nslookup` to resolve domain names and gather additional information.

## Subdomain Enumeration
Enumerate subdomains to discover additional targets. Use tools like `sublist3r` and `amass` to find subdomains associated with the target domain.

## Passive Enumeration
Gather information passively by monitoring public sources. Look for information in social media, forums, and other public sources that may provide clues about the target network.

## Active Enumeration
Actively interact with the target network to gather more detailed information. Use tools like `nmap` with the `-sC` flag to run default scripts and gather more information.

## Conclusion
Summarize the findings from the enumeration process. Identify potential targets and vulnerabilities that can be exploited.
