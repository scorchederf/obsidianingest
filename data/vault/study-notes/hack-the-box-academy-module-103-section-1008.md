# Hack The Box - Academy Module 103 Section 1008

## Overview
This module covers various techniques and tools for password cracking and credential harvesting, including passive and active subdomain enumeration, and the use of tools like John the Ripper, Hashcat, and Kerbrute.

## Password Cracking Tools
- **John the Ripper**: A password cracker that supports a variety of password hashing algorithms.
- **Hashcat**: A powerful password recovery tool that supports a wide range of hash types.
- **Lazagne**: A tool that collects various credentials from the Windows registry, browsers, and other locations.

## Credential Harvesting
- **Kerbrute**: A tool used to brute-force Kerberos tickets, which can be used to gain access to network resources.

## Subdomain Enumeration
- Passive subdomain enumeration: Techniques to discover subdomains without actively probing the target.
- Active subdomain enumeration: Techniques that involve active probing to discover subdomains, such as using tools like `fierce` and `sublist3r`.

## Tools Usage
- **John the Ripper**: Usage examples and command syntax for cracking passwords.
- **Hashcat**: Usage examples and command syntax for cracking hashes.
- **Lazagne**: Usage examples and command syntax for harvesting credentials.
