# Using the Metasploit Framework

## Introduction
This section introduces the Metasploit Framework, a powerful tool for penetration testing and ethical hacking. It covers the basics of using Metasploit for various types of attacks, including exploitation, post-exploitation, and reporting.

## Installation and Setup
To install Metasploit, follow the official documentation. Once installed, you can start the Metasploit console by running the command `msfconsole`. The console provides a command-line interface for executing various tasks.

## Using Metasploit Modules
Metasploit modules are categorized into different types, such as exploits, payloads, post-exploitation, and auxiliary. To use a module, you can search for it by name or category. For example, to search for a module, you can use the command `search [module_name]`.

## Exploitation
Metasploit can be used to exploit vulnerabilities in target systems. To exploit a target, you can use the `use` command followed by the module name. For example, to use the `exploit/unix/ssh/ssh_login` module, you would run `use exploit/unix/ssh/ssh_login`. You can then set options such as the target IP, username, and password.

## Post-Exploitation
After gaining access to a target system, you can use Metasploit to perform post-exploitation tasks. These tasks include privilege escalation, data exfiltration, and persistence. To run a post-exploitation module, use the `use` command followed by the module name. For example, to use the `post/multi/gather/enum_users` module, you would run `use post/multi/gather/enum_users`.

## Reporting
Metasploit provides various reporting options to document your findings. You can generate reports in different formats, such as HTML, PDF, and text. To generate a report, use the `report` command followed by the report type. For example, to generate an HTML report, you would run `report -h`.
