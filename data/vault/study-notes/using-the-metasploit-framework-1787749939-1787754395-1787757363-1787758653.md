# Using the Metasploit Framework

## Introduction
This section introduces the Metasploit Framework, a powerful tool for penetration testing and ethical hacking. It covers the basics of using Metasploit to identify and exploit vulnerabilities in a target system.

## Installation
To install Metasploit, follow these steps:

1. Install Ruby and necessary dependencies.
2. Download and install Metasploit from the official website.
3. Start the Metasploit console using the command: `msfconsole`

Ensure that you have the latest version of Metasploit for the best functionality.

## Basic Commands
Here are some basic commands to get started with Metasploit:

- `search <keyword>`: Search for modules based on a keyword.
- `use <module>`: Select a module to use.
- `show options`: Display the options for the currently selected module.
- `set <option> <value>`: Set the value for a specific option.
- `run`: Execute the current module.

## Module Usage
Metasploit modules are categorized into different types, such as exploits, payloads, and auxiliary modules. Here’s an example of using an exploit module:

1. Search for an exploit module: `search exploit`
2. Use a specific module: `use exploit/multi/handler`
3. Set the required options: `set payload linux/x86/shell_reverse_tcp`
4. Set the LHOST and LPORT: `set LHOST <your_ip_address>`
5. Set the LPORT: `set LPORT <your_port_number>`
6. Run the module: `run`

This will start a reverse shell listener on the specified IP and port.

## Payloads
Payloads are used to interact with the target system once a successful exploit has been executed. Common payload types include:

- `shell`: Provides a command-line interface to the target system.
- `meterpreter`: Provides a more advanced interface with additional features.
- `reverse_tcp`: Establishes a reverse shell connection.

To use a payload, set the `payload` option in the module configuration.

## Auxiliary Modules
Auxiliary modules are used for reconnaissance and information gathering. For example, the `auxiliary/scanner/portscan/tcp` module can be used to scan a target for open ports:

1. Use the module: `use auxiliary/scanner/portscan/tcp`
2. Set the target IP: `set RHOSTS <target_ip>`
3. Set the port range: `set PORTS 1-1024`
4. Run the module: `run`

This will scan the target IP for open ports in the specified range.
