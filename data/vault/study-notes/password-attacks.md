# Password Attacks

## Password Attacks
Password attacks are a common method used by attackers to gain unauthorized access to systems. This module covers various techniques and tools used in password attacks, including brute-forcing, cracking, and enumeration.

### Tools
- **John the Ripper (john)**: A password cracker that can be used to crack hashes.
- **Hashcat (hashcat)**: A powerful password cracking tool that supports a wide range of hash types.
- **HashID (hashid)**: A tool for identifying and displaying hash types.
- **Lazagne (lazagne)**: A password recovery tool that can extract passwords from various applications.
- **Mimikatz (mimikatz)**: A post-exploitation tool that can extract credentials from memory.

### Techniques
- **Password Cracking**: Techniques for cracking passwords, including brute-forcing and dictionary attacks.
- **Credential Dumping**: Techniques for extracting credentials from memory or files.

### Tactics
- **Passive Subdomain Enumeration**: Techniques for passively gathering information about subdomains.
- **Active Subdomain Enumeration**: Techniques for actively probing subdomains for vulnerabilities.
