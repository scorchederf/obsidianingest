# Alias Files

## Description
Alias files are used to create shortcuts or symbolic links to files or directories. They can be used to hide the true location of files or directories, making them useful for evading detection or for creating backdoors. This note covers the use of alias files in various contexts.

## Usage
Alias files can be created and used in different ways depending on the operating system. Here are some examples:

- **Windows**
  ```bash
  mklink /D C:\alias C:\real\path
  ```
  This command creates a directory junction named `C:\alias` that points to `C:\real\path`.

- **Linux**
  ```bash
  ln -s /real/path /alias
  ```
  This command creates a symbolic link named `/alias` that points to `/real/path`.

## Notes
Alias files can be used to hide the true location of files or directories, making them useful for evading detection or for creating backdoors. It is important to be cautious when using alias files, as they can also be used maliciously.
