# Hack The Box - Academy Module 115 Section 1124

## Introduction
This section of the Hack The Box Academy covers the use of tools such as Ettercap, Burpsuite, and Bettercap for network reconnaissance and exploitation. The focus is on understanding how to use these tools effectively in a penetration testing environment.

## Ettercap
Ettercap is a suite of tools for man-in-the-middle attacks. It includes features such as ARP spoofing, content filtering, and session hijacking. The section covers how to set up and use Ettercap to intercept and manipulate network traffic.

## Burpsuite
Burpsuite is a powerful web application security testing tool. The section explains how to use Burpsuite for various tasks such as intercepting and modifying HTTP(S) traffic, performing security testing, and identifying vulnerabilities in web applications.

## Bettercap
Bettercap is a network security tool that can be used for a variety of tasks, including network reconnaissance, man-in-the-middle attacks, and security testing. The section covers how to use Bettercap to perform network scanning and exploit vulnerabilities.
