# Hack The Box - Academy Module 134 Section 1186

## Overview
This section covers the use of Mimikatz, John the Ripper, and Hashcat for password attacks. It also discusses techniques for lateral movement and privilege escalation.

## Password Attacks
The section explains the usage of Mimikatz, John the Ripper, and Hashcat for password attacks. It covers the following commands and techniques:

- Mimikatz commands for extracting credentials
- John the Ripper for brute-forcing passwords
- Hashcat for cracking hashes

The techniques T1003 and T1059 are discussed in the context of these tools.

## Lateral Movement and Privilege Escalation
The section covers techniques for moving laterally within the network and escalating privileges. It includes the following:

- T1003 - Pass-the-Ticket
- T1059 - Token Manipulation

These techniques are relevant for the use of Mimikatz and other tools.
