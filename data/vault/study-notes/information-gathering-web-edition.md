# Information Gathering - Web Edition

## Introduction
This section covers the techniques and tools used for web information gathering, including passive and active subdomain enumeration, file inclusion, and crawling.

## Tools
The following tools are discussed and used in the web information gathering process:

- Aquatone
- Burpsuite
- Gobuster
- FFUF
- Fierce

These tools are used for various purposes such as subdomain enumeration, file inclusion, and crawling.

## Subdomain Enumeration
Subdomain enumeration is a critical step in the information gathering process. The following tools are used for this purpose:

- Aquatone
- Burpsuite
- Gobuster
- FFUF
- Fierce

These tools help in discovering additional subdomains that may be associated with the target.

## File Inclusion
File inclusion is a technique where attackers can include files from the server to gain additional information or execute code. The following tools are used for file inclusion:

- Gobuster
- FFUF
- Fierce

These tools help in identifying files that can be included and potentially exploited.

## Crawling
Crawling involves traversing the website to discover additional information and resources. The following tools are used for crawling:

- Gobuster
- FFUF
- Fierce

These tools help in discovering hidden directories and files on the website.
