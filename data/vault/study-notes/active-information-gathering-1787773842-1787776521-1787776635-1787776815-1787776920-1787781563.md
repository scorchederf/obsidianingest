# active-information-gathering

## Vulnerability Scanning
- Nessus Scanner
  - download and install https://www.tenable.com/downloads/nessus
    ```shell sudo apt install ./Nessus-X.X.X.deb```
  - start the service
    ```shell sudo service nessusd start```
  - access the web interface
    [https://localhost:8834](https://localhost:8834)
  - change a user password
    ```shell sudo /opt/nessus/sbin/nessuscli chpasswd admin```
- nmap via nmap scripting engine (NSE)
  - run all the scripts under vuln
    ```shell sudo nmap --script vuln 10.11.1.10 ```
