# Hack The Box - Academy Module 115 Section 1109

## Overview
This module covers various techniques and tools used in ethical hacking, including password cracking, network scanning, and post-exploitation. The content is based on the Hack The Box Academy module 115, section 1109.

## Password Cracking
The module discusses the use of tools like `john` and `lazagne` for password cracking. It covers techniques such as dictionary attacks and brute-forcing.

## Network Scanning
Network scanning is covered using tools like `nmap`. The module explains how to perform comprehensive scans to identify open ports and services.

## Post-Exploitation
Post-exploitation techniques are discussed, including the use of `mimikatz` for privilege escalation and `sqlmap` for SQL injection attacks.

## Tools
The module introduces several tools such as `burpsuite` and `ettercap` for web application testing and network manipulation. It also covers `john` for password cracking, `lazagne` for credential dumping, and `mimikatz` for privilege escalation.
