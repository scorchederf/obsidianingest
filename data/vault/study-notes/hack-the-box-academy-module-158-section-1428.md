# Hack The Box - Academy Module 158 Section 1428

## Overview
This section of the Hack The Box - Academy covers the process of identifying and exploiting a web application vulnerability. The focus is on understanding the vulnerability, crafting a payload, and executing it to gain access to the system.

## Identifying the Vulnerability
The vulnerability is identified through a web application that appears to be vulnerable to a SQL Injection attack. The application is running on a web server with a known version that is susceptible to this type of attack.

## Crafting the Payload
A payload is crafted to exploit the SQL Injection vulnerability. The payload is designed to execute a SQL query that will return sensitive information from the database.

## Executing the Payload
The payload is executed by sending a crafted HTTP request to the vulnerable web application. The response from the server contains the sensitive information, which can be used to gain further access to the system.

## Exploiting the Vulnerability
Once the sensitive information is obtained, the next step is to use it to gain further access to the system. This may involve using the information to log in as a different user or to execute additional commands on the server.
