# Hack The Box - Academy Module 110 Section 1051

## Overview
This section of the Hack The Box Academy Module 110 covers techniques and tools for performing password cracking and lateral movement. It includes a detailed walkthrough of using tools like John the Ripper, Hydra, Nmap, and Impacket for various penetration testing tasks.

## Password Cracking
The section discusses the use of John the Ripper and Hydra for password cracking. It provides examples and commands for using these tools to crack passwords, including common password lists and wordlists.

## Network Scanning
Nmap is introduced as a tool for network scanning. The section includes commands and examples for using Nmap to discover open ports and services on a target network.

## Lateral Movement
Impacket is covered for its capabilities in performing lateral movement. The section provides examples of using Impacket to execute remote commands and access shares on a network.

## Credential Harvesting
Lazagne is discussed as a tool for harvesting credentials from various applications. The section includes commands and examples for using Lazagne to extract stored credentials from memory and other locations.
