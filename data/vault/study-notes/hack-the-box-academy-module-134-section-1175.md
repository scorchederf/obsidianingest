# Hack The Box - Academy Module 134 Section 1175

## Overview
This section covers the use of tools such as Aquatone, BetterCap, and BurpSuite to perform reconnaissance and enumeration tasks. It also discusses techniques related to web attacks and lateral movement.

## Tools
- **Aquatone**: A tool for generating HTML reports from URLs, useful for web enumeration.
- **BetterCap**: A network security tool that can be used for various network attacks, including HTTP/HTTPS traffic analysis.
- **BurpSuite**: A web application security testing platform that can be used for intercepting and manipulating HTTP(S) traffic.
