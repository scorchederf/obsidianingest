# Hack The Box - Academy Module 57 Section 491

## Overview
This section covers the use of Burp Suite for web application security testing, focusing on passive and active enumeration techniques. The goal is to identify and exploit vulnerabilities in web applications.

## Passive Enumeration
Passive enumeration involves gathering information about the target without directly interacting with the application. This can include analyzing the source code, headers, and other metadata to identify potential vulnerabilities.

- **Tools Used:** Burp Suite
- **Techniques:** Web-attacks

## Active Enumeration
Active enumeration involves actively interacting with the application to identify and exploit vulnerabilities. This can include brute-forcing, SQL injection, and other techniques.

- **Tools Used:** Burp Suite
- **Techniques:** Web-attacks

## Using Burp Suite
Burp Suite is a powerful tool for web application security testing. It includes features such as proxying, intercepting, and modifying HTTP(S) traffic.

- **Steps to Use Burp Suite:**
  1. Set up Burp Suite to intercept traffic.
  2. Configure the target application to use Burp Suite as its proxy.
  3. Analyze the intercepted traffic to identify potential vulnerabilities.
  4. Use Burp Suite's tools to exploit identified vulnerabilities.
