# Hack The Box - Academy Module 58 Section 526

## Overview
This module covers various techniques and tools used in web application penetration testing. The techniques include crawling, DNS enumeration, file inclusion, local port forwarding, reverse port forwarding, SQL injection, and web attacks. The tools mentioned include Aquatone and Bash.

## Techniques
- **Crawling**: Techniques for exploring and mapping the target web application.
- **DNS Enumeration**: Methods for gathering information about the target domain and its subdomains.
- **File Inclusion**: Exploiting file inclusion vulnerabilities to gain access to sensitive files.
- **Local Port Forwarding**: Using tools like `socat` to forward local ports to remote services.
- **Reverse Port Forwarding**: Setting up a reverse tunnel to access local services from a remote machine.
- **SQL Injection**: Techniques for exploiting SQL injection vulnerabilities to manipulate database queries.
- **Web Attacks**: General methods for attacking web applications, including injection attacks and other common vulnerabilities.

## Tools
- **Aquatone**: A tool for generating screenshots and HTML reports of a website. It can be used to identify and exploit various web application vulnerabilities.
- **Bash**: A command-line shell used for executing commands and scripts. It is a fundamental tool in many penetration testing scenarios.
