# PEASS-ng

## Description
PEASS-ng is a suite of privilege escalation awesome scripts designed for both Windows and Linux environments. It is part of the new generation of tools aimed at identifying potential vulnerabilities and misconfigurations that can be exploited to escalate privileges.
