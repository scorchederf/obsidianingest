# SecLists Wordlists

## Description
The SecLists repository on GitHub contains a variety of wordlists for security testing. The wordlists were originally made in 2007 and are now considered obsolete for certain purposes. However, they are still recommended for testing modern web environments.

Specifically, the following wordlists are recommended:

- `Discovery/Web-Content/combined_words.txt`
- `Discovery/Web-Content/combined_directories.txt`
