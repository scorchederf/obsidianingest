Placeholders Value Description
{field:$FIELD_NAME} field:$FIELD_NAME Extracts the value of $FIELD_NAME from the field in the first event from the trigger. Put field names with spaces in double quotes, {field:"My Field"}.
{field_raw:$FIELD_NAME} field_raw:$FIELD_NAME Extracts the value of $FIELD_NAME from the field in the first event from the trigger without JSON escaping it. Put field names with spaces in double quotes, {field_raw:"My Field"}.
{name}, {alert_name} name, {alert_name} The user-made name of the trigger.
{description}, {alert_description} description, {alert_description} A user-made description of the trigger.
{triggered_timestamp}, {alert_triggered_timestamp} triggered_timestamp, {alert_triggered_timestamp} The time at which the trigger was triggered, formatted as ISO 8601.
{id}, {alert_id} id, {alert_id} The id of the trigger.
{action_id}, {alert_notifier_id} action_id, {alert_notifier_id} The id of the Action used to deliver this message.
{event_count} event_count The number of events from the trigger.
{url} url A URL to open LogScale with the trigger's query.
{query_result_summary} query_result_summary Events encoded as a string.
{query_string} query_string The query of the trigger.
{query_start_s} query_start_s The actual query start time as Unix Time in seconds with 3 decimals.
{query_end_s} query_end_s The actual query end time as Unix Time in seconds with 3 decimals.
{query_time_start} query_time_start The specified query start time (e.g. 10m).
{query_time_end} query_time_end The specified query end time (e.g. now).
{query_time_interval} query_time_interval The specified time interval for the Alert's query (e.g. 10m -> now).
{query_start_ms} query_start_ms The actual query start time as Unix Time in milliseconds.
{query_end_ms} query_end_ms The actual query end time as Unix Time in milliseconds.
{query_start_datetime} query_start_datetime The actual query start time formatted as ISO 8601.
{query_end_datetime} query_end_datetime The actual query end time formatted as ISO 8601.
{warnings} warnings Any warnings that were generated by the query. Note that by default, triggers will not trigger if there are warnings from the query, see Setting Alert Throttle Period and Scheduled Searches.
{repo_name} repo_name The name of the repository in which the query was executed.
{events_str} events_str Events encoded as a string.
{events} events Events encoded as a JSON array of event objects.
{events_html} events_html Events encoded as an HTML table inside <table> tags. All fields from all events are shown as columns. The columns are ordered by the order the fields are encountered, starting with the fields from the first event. If you want fewer fields, remove them in the Alert or Scheduled Search query using e.g. table(), select() or drop() You can also specify the order of the fields using table() or select()
{schedule} schedule The cron schedule which the triggering search was executed according to. Only applicable when triggered by a Scheduled Searches.
{time_zone} time_zone The time zone that the triggering search is performed within. Only applicable when triggered by a Scheduled Searches.
{trigger_type} trigger_type Can either be 'Alert' or 'Scheduled Search' depending on which triggered the action.
